AI Customizer

Unity tool - Runtime character body customization

Turns a rigged character into a customizable one in a single click. Players adjust height, chest, waist, hips, head and jaw with auto-generated sliders, and equipped outfits stretch together with the body.

  • One-click editor pipeline: drop a character, press Run, get a ready-to-use prefab.
  • Skeleton-hierarchy analysis in pure C#: no server, no ML model, no GPU warm-up (11.9 ms for a 57-bone character).
  • Works with Humanoid and Generic rigs, including Mixamo naming.
  • Outfit fitting and a Skin Weight Transfer tool for unrigged clothing.
  • Auto-generated runtime slider UI with JSON preset save/load; runs in builds.
